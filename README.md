# Amazon-Products-Sentiment-Dashboard
Amazon Products Sentiment & Customer Reviews Dashboard
Project Overview
This project analyzes Amazon product customer reviews using Python for sentiment analysis and Power BI for interactive data visualization. The dashboard helps identify customer satisfaction trends, product ratings, and sentiment distribution.
Tools & Technologies
Power BI
Python (Sentiment Analysis)
Pandas
TextBlob / NLTK
DAX
Power Query
Key Features
Analysis of 21.94K customer reviews.
Average product rating of 4.54.
Sentiment classification into Positive, Neutral, and Negative using Python.
Interactive filters by Brand and Product Name.
KPIs displaying positive and negative sentiment percentages.
Visual comparison of sentiment across different Amazon products.
Insights
88.62% of customer reviews are positive.
Only 4.24% of reviews are negative.
Most Amazon products receive highly positive customer feedback, with only a few products showing relatively higher negative sentiment.
